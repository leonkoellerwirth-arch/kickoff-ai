# Reviews

This directory contains dated, evidence-based reviews of the public repository.

Reviews must first state the repository's intended outcome and boundaries as
understood from the authoritative documentation. Findings then use the format
defined in `CONSTITUTION.md` §11: claim, evidence, interpretation,
counter-check, and a scoped action item. Reviews distinguish verified defects
from open decisions and from deliberate trade-offs.

Because this is a public GitHub repository, each review considers a first-time
visitor who may clone or execute the documented bootstrap path. It therefore
examines public claims, contributor experience, supply-chain and publication
risks, repository hygiene, and the accuracy of the verification story.

Reviews are assessments, not implementation plans. They must not include
private-machine data, secrets, personal paths, customer names, or unverified
claims.
