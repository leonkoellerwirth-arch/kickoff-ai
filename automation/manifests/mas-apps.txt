# automation/manifests/mas-apps.txt
# Declarative list of App Store apps for `mas install` / `mas upgrade`.
# Managed via: mac-update --only mas (updates), mas install <id> (first install).
#
# Format: <mas-id> <app-name>
#         start comments with #.
#         Find IDs: mas search "<App-Name>"  or  mas list
#
# Usage:
#   mas list                        # Shows all installed apps with IDs
#   mas search "App Name"           # Search for ID
#   mas install <id>                # Install
#   mac-update --only mas           # Update all apps
#
# Prerequisite: brew install mas (included in Brewfile.automation)
#
# NOTE: Many installed apps (from INVENTORY §10) were not obtained via the
# App Store (Adobe CC, JetBrains, Docker, etc.) and do not appear here.
# Only apps verifiably installed via the App Store are listed.
#
# IDs are stable, but verify with `mas list` on the machine — the IDs
# listed below are best-effort from public sources. Use `mas list`
# to see the IDs of all apps actually installed via the App Store.
